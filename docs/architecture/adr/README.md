# Architecture Decision Records

Use this directory for concise ADRs when a technical decision changes the
architecture in `docs/architecture/v1-architecture-and-tech-stack.md`.

Recommended ADR shape:

1. Title and status: proposed, accepted, superseded, or rejected.
2. Context and source anchors.
3. Decision.
4. Consequences and follow-up work.
5. Supersedes or superseded-by links, if applicable.

Do not store raw secrets in ADRs. Reference external secret locations only.
